# 家的下一站｜家事法律

家事法律服務網站。網站內容由 Next.js 產生為靜態頁面，並透過 GitHub Actions 部署至 GitHub Pages。

唯一正式網站：<https://lawyerhao83-maker.github.io/home-next-family-law/>

正式發布來源為 `lawyerhao83-maker/home-next-family-law` 的 `main` 分支。不要將正式更新發布到 OpenAI Sites 或 `home-next-family-law-2.0`。

## 本機預覽

```bash
npm install
npm run dev
```

## 部署

推送至 `main` 分支後，GitHub Actions 會自動建立並發布網站。網址中的專案路徑會依倉庫名稱自動調整。
